# vr-oi-simulator
VR OI 参赛模拟器

一个纯前端的网页游戏：用 Three.js 搭建 3D 考场，以第一人称视角参加 4 小时模拟 OI 竞赛。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无本地依赖。Three.js（r128）已随
仓库附带在 `assets/vendor/three.min.js`，离线也能玩；若本地文件缺失会回退到
cdn.jsdelivr.net，两次都失败时页面会给出明确提示。

## 目录结构

```
index.html            页面外壳：head / body 标记 / 脚本加载顺序
assets/
  css/main.css        全部样式（原 index.html 内联 <style>）
  vendor/three.min.js Three.js r128（本地优先，CDN 回退）
  keywords.js         评分用 C++ 关键字表（静态数据）
  problems/_pool.js   题库注册表 PROBLEM_DATA + 起始代码模板（须最先加载）
  problems/P*.js      每题一个文件，格式为 PROBLEM_DATA.push({ ... })
js/
  judge.js            评测评分逻辑
  npc-gen.js          NPC 代码生成器（确定性）
  problems.js         题库逻辑：按 id 索引 / 每局抽 4 题
  core.js             工具函数 / 全局状态 / 几何材质缓存 / 音频 / DOM 引用 / 视角设置
  dialog3d.js          3D 悬浮弹窗：无遮罩、球面跟随、惯性、canvas 按钮拾取
  feedback.js         Toast 提示与成就解锁
  hp.js               玩家血条（监考倒台后显示）与受击反馈
  world.js            考场场景：房间 / 桌椅 / 显示器 / 人物 / 保安
  interact.js         准星交互判定（E / F / 空格）
  combat.js           殴打老师 / 保安 AI / 全员收尾
  arcade.js           街机强化：连击 / 击杀飘字 / 掉落补给 / 冲刺 / 应援 / 氛围事件
  debris.js           击中爆散：形状感知的刚体物理（与地板/墙壁碰撞）
  npc.js              屏蔽词机制与选手 NPC 行为
  teacher.js          监考老师：警告 / 惩罚 / 举手对话
  corridor.js         走廊往返与洗手间流程
  ide.js              IDE 面板 / 语法高亮 / 提交评测
  paper.js            草稿纸手写板
  look.js             FPS 视角 / 指针锁定 / 玩家移动 / 小地图
  reticle.js          3D 准星：45° 交互旋转 / 攻击红化放大 / 停留进度环
  tension.js          紧张值系统：灯光压暗 / 色偏 / 暗角 / 心跳 / 抖动 / 拖影
  postfx.js           全局动态模糊（AfterimagePass，CDN 失败自动回退）
  save.js             进度存档读写（localStorage）
  ending.js           比赛结算与结局分支
  main.js             事件绑定 / 主循环 / 初始化入口
```

JS 全部是传统脚本（非 ES Module），按 index.html 中的顺序加载并共享全局作用域，
新增模块时注意把被依赖的定义放在前面。

## 加题

1. 在 `assets/problems/` 新建一个以题目 id 命名的文件（如 `P10001.js`）；
2. 内容为 `PROBLEM_DATA.push({ id, name, max, tl, ml, desc, starter: STARTER_TEMPLATE });`；
3. 在 `index.html` 中按同样格式补一行 `<script>` 引入。

## 隐藏结局

殴打监考老师会叫来保安。保安总出场名额上限为 200 人（`GUARD_MAX_TOTAL`），
耗尽后不再补充。击倒全部 200 人触发隐藏结局「无人能挡」。
随着击倒数上升，紧张值（`js/tension.js`）会逐渐拉满：灯光压暗、雾色转暗红、
屏幕暗角随心跳收缩、对比度增强、镜头抖动加剧、全局拖影变长。
回座位静坐可以让紧张值部分回落，但贴身追来的保安不受影响。
击倒 10 / 20 / 50 / 100 名保安各有成就；从第 10 杀起每次击杀有 4%
概率弹出保安队通报（语气逐渐升级，配合可缓和，嘴硬会推高紧张值并叫来更多保安）。
出拳有视角扇形窗口（准星前约 51°），且一拳会扫倒范围内全部保安；
监考倒台之后，同学也会进入可攻击范围。
保安通报弹出的瞬间，整个世界放慢到 0.1x（考试计时不受影响），
 选项落地后恢复原速。监考倒台同时亮出 3 格血条；被保安抓住扣 1 格
（窗口闪红 + 提示），血量耗尽才被抓走。
慢放覆盖整个世界：玩家移动、跳跃、受击间隔（玩家侧 1s 无敌）都按
世界时钟同比例变慢，只有考试计时和镜头转向保持原速。空格跳跃
（空中不受桌面阻挡，落点卡进障碍会退回起跳点）；打倒监考后同学
也可被攻击，打击感与打保安一致。
通报弹窗只剩“不配合”选项。受击无敌改为玩家侧：1 秒内无论几个保安
都只掉一格。打完全部 200 人不会直接结算——走廊尽头那扇门会打开，
门口填满极强的白光并向房内投射，伴随“门开了”警告弹窗；走向门口按 E
“走出去”之后才进入隐藏结局「无人能挡」。白光区域里准星与交互文字会
自动反色以保证可读。

## 街机强化（arcade.js）

- **连击**：连续击倒计入连击，3.2 秒无击杀即清零。阈值增益：
  ×5 疾步（移速 +12%）、×10 拳威（拳锋范围 +0.7m）、
  ×15 残像（命中顿帧增强）、×20 心流（回 1 格血）。
  连击数显示在画面右侧，断裂时弹出 COMBO LOST。被保安命中也会断连击。
- **击杀飘字**：目标头顶投影出 KO!/踉跄!/+1❤/疾速! 等字，多杀时
  屏幕中央会播报「双杀!!/三杀!!/狂杀!!」。
- **保安种类**（随击倒数逐步登场）：普通保安；重装保安（击杀 8 后
  约 20%，两段血、体形更大、速度慢）；快速保安（击杀 4 后约 46%，
  速度快、体形小）。
- **掉落补给**：保安倒地随机掉落矿泉水（回 1 格血，满血时短暂疾速）
  或红牛（14 秒疾速：移速 +25%、冲刺冷却减半），走近自动拾取；
  重装保安必定掉落。同屏最多 6 件，30 秒后消失。
- **冲刺**：Q 键向移动方向（无输入时向前）0.16 秒冲刺 2.4m，
  冷却 1.3 秒，FOV 轻微拉近，自带音效，贴身保安会被撞开。
- **同学应援**：打倒监考后，坐着的同学会随机加油；保安贴身时
  提醒后路、残血时喊你捡补给。
- **氛围事件**：开打后每隔 30 秒左右随机出现灯管闪烁、广播电流
  杂音、挂钟滴答等小事件。
- **新成就**：连击宗师（×15）、心流之王（×30）、考场拾荒者
  （拾 5 件补给）、拆墙专业户（放倒 10 名重装）、考场博尔特
  （冲刺 30 次）；结算页新增「最大连击 / 拾取补给 / 武器收集」统计。

## 武器系统（weapons.js）

六件武器（4 近战 + 2 投掷）各有独立的 锋距 / 扇形 / 伤害 / 冷却 / 击退 / 动画：

| 武器 | 获得方式 | 锋距 | 扇形 | 伤害 | 冷却 | 特色 |
|------|---------|------|------|------|------|------|
| 拳头 | 初始拥有 | 2.2m | 51° | 1 | 无 | 快拳；重装保安需两拳 |
| 键盘 | 开局在讲台附近拾取 | 2.6m | 63° | 2 | 0.45s | 宽弧扇面，一击破重装 |
| 椅子 | 开局在右墙过道拾取 | 3.0m / 不限距 | 57° | 3 | 0.85s | 两用重武器：贴身抡扫 AOE；无近身目标时整把丢出，砸落处 2.6m 群伤 + 击退 |
| 直尺 | 开局在黑板前拾取 | 3.6m | 32° | 1.5 | 0.5s | 突刺：最远锋距，窄但快 |
| 粉笔头 | 开局在讲台旁拾取 | 不限距 | 12° | 1 | 0.55s | 投掷：直线快弹道，准星打哪飞哪，命中白灰四散 |
| 橡皮 | 开局在黑板前拾取 | 不限距 | 16° | 2 | 1.15s | 投掷：低弹道重掷，一击破重装，击中闷响 |

- 数字键 1-6 切换（弹窗操作时数字键仍留给选项）；拾取新武器会自动装备。
- 开局考场即刷出五处发光拾取点；后期保安也会小概率掉落「你还没拿到」
  的武器。投掷类武器不限距离：准星内有保安会显示距离提示，没有目标
  也能空投；弹道经空气托举修正，能覆盖整间教室（屋顶对角约 20m），
  只要砸中人（不限远近）即生效。数字键 1-6 或鼠标滚轮切换武器。
- 第一人称手持模型跟随镜头，挥击带下劈/突刺动画与专属音效；
  右下 HUD 显示 6 个槽位与当前武器冷却条。
- 重装保安被高伤害武器命中会「重击踉跄」：击退更远、火花更多。
- 武器击杀会计入独立成就：键盘侠（20）、板凳战神（30）、
  尺有所长（15）、粉笔刺客（20）、橡皮擦掉你（15）、
  全副武装（集齐 4 件近战）。
